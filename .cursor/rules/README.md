# PointMe Cursor Rules

This directory contains rule files that provide context and guidelines for AI assistants working with the PointMe codebase. These rules are automatically applied by the Cursor IDE to ensure consistent, high-quality AI assistance.

## Rule Files

### 1. ai_cascade_directive.mdc
- **Priority**: 1 (Highest)
- **Purpose**: Provides high-level directives for AI assistants to maintain continuity and consistency across development sessions
- **Key Sections**:
  - Project Context
  - Cascade Principles
  - Development Workflow
  - Critical Areas
  - Documentation Requirements

### 2. ai_continuity_rules.mdc
- **Priority**: 2
- **Purpose**: Ensures continuity across AI-assisted development sessions
- **Key Sections**:
  - Session Continuity Protocol
  - Project Memory
  - AI Interaction Guidelines
  - Learning Repository

### 3. pointme-rules.mdc
- **Priority**: 3
- **Purpose**: Provides detailed implementation guidelines for the PointMe project
- **Key Sections**:
  - Architectural Enforcement
  - Code Validation Matrix
  - File Structure
  - Coding Standards
  - Critical Services
  - Priority Stack
  - Documentation Requirements

### 4. point-me-debugging-rules.mdc
- **Priority**: 4
- **Purpose**: Provides context for debugging specific issues in the PointMe project
- **Key Sections**:
  - Active Crisis Points
  - Real-Time File Tree
  - Change Detection
  - Automatic Context Updates

## Usage

These rules are automatically applied by the Cursor IDE when working with the PointMe codebase. They provide AI assistants with the context and guidelines needed to provide consistent, high-quality assistance.

## Maintenance

Rules should be updated regularly to reflect the current state of the project:

1. Update `ai_cascade_directive.mdc` when project focus or critical areas change
2. Update `ai_continuity_rules.mdc` when new patterns are identified or project memory needs updating
3. Update `pointme-rules.mdc` when implementation guidelines change
4. Update `point-me-debugging-rules.mdc` when debugging specific issues
